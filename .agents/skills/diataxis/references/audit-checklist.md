# 文档审计清单

用于盘点并重组现有文档。逐项勾选，未通过项记录处理动作。

## 1. 盘点

- [ ] 已列出全部文档路径与标题
- [ ] 已记录每篇的首段与目录层级
- [ ] 已标出重复或高度相似的文档

## 2. 分类

- [ ] 每篇都标了唯一象限（tutorial / how-to / reference / explanation）
- [ ] 标不出的文档已确认是否缺少明确读者需求
- [ ] 标题能直接反映读者需求

## 3. 混装检测

- [ ] 教程中无完整参数表、无大段原理
- [ ] 指南中无零基础教学、无长篇背景
- [ ] 参考中无主观建议、无步骤叙事
- [ ] 解释中无操作步骤、无参数罗列

## 4. 拆分与重组

- [ ] 混装文档已按象限拆分
- [ ] 拆分后每篇骨架完整
- [ ] 原文链接已重定向，无死链
- [ ] 目录结构有明确组织原则（按象限或按主题）
- [ ] 入口页能按「学 / 做 / 查 / 懂」四问分流

## 5. 一致性

- [ ] 术语、命令、参数与实现一致
- [ ] 版本差异有单独说明
- [ ] 跨篇引用使用链接而非复制
- [ ] 代码块可复制、可运行

## 6. 回归

- [ ] 随机抽一篇教程，能独立走通
- [ ] 随机抽一篇指南，能解决目标任务
- [ ] 随机抽一个参考条目，能查到默认值与类型
- [ ] 随机抽一篇解释，能说清一个「为什么」
