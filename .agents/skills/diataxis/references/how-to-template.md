# How-to 操作指南模板

任务导向、行动导向。读者已有基础，只想把某件事做成。

## 骨架

```markdown
# 如何 <完成某个具体任务>

一句话说明适用场景和结果。

## 适用场景

- 什么时候需要这篇指南
- 不适用的情况及替代链接

## 前置条件

- 已具备的环境、权限、前置步骤

## 步骤

1. <动作>
2. <动作>
3. <动作>

每步给命令或配置，并说明成功标志。

## 验证

如何确认任务完成。

## 常见问题

- 报错 A：原因与处理
- 现象 B：检查点
```

## 写作要点

- 标题必须是任务句：「如何……」「……时怎么办」「把 X 迁移到 Y」。
- 默认读者懂基础概念，不铺垫背景。
- 步骤可跳读：编号清晰，每步独立可执行。
- 允许分叉，但每个分叉都要有明确条件（「如果你用 Docker……」）。
- 不追求覆盖全部，只覆盖这个任务。

## 最小示例

```markdown
# 如何把现有项目切换到 pnpm

适用于已有 `package-lock.json` 的 Node 项目。首次搭建项目请看教程。

## 前置条件

- Node.js 18+
- 已安装 pnpm：`pnpm -v` 有输出

## 步骤

1. 删除旧锁文件：

       rm package-lock.json

2. 生成 pnpm 锁文件：

       pnpm install

3. 确认依赖可运行：

       pnpm run build

## 验证

- 仓库出现 `pnpm-lock.yaml`
- `pnpm run build` 退出码为 0

## 常见问题

- `ERR_PNPM_PEER_DEP_ISSUES`：先按提示补 peer 依赖，或临时用 `--strict-peer-dependencies=false`。
```
