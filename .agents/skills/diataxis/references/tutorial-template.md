# Tutorial 教程模板

学习导向、行动导向。目标是让读者跟着做完，得到一个能运行的结果。

## 骨架

```markdown
# 教程标题（含成品名，如「用 X 搭建第一个 Y」）

一句话说明读者做完会得到什么。

## 你将完成

- 成品截图或效果描述
- 预计耗时

## 前置条件

- 环境、版本、账号、依赖
- 检查命令及预期输出

## 步骤

### 1. 安装依赖

命令：

    <command>

预期输出：

    <output>

### 2. 初始化项目

...

### 3. 运行并验证

...

## 你完成了什么

- 回顾关键节点
- 指向下一步：概念解释 / 操作指南 / 参考
```

## 写作要点

- 一条主线，不设分支；需要分支时另开教程。
- 每步都有可观察的结果（输出、截图、页面）。
- 代码块完整可复制，不省略关键行；省略处用注释标明。
- 用「我们将」「你会看到」，不用「你可以选择」。
- 首次出现的术语就地一句话解释，详细原理链接到解释文档。

## 最小示例

```markdown
# 用 CLI 生成第一份报告

读完本教程，你会用 `report` 命令把一份 CSV 转成 HTML 报告。

## 前置条件

- 已安装 Node.js 18+
- 终端能执行 `node -v`，输出 `v18.x` 或更高

## 步骤

### 1. 安装

    npm install -g report-cli

预期：命令无报错，`report -v` 输出版本号。

### 2. 准备数据

    echo "name,score" > scores.csv
    echo "alice,90" >> scores.csv

### 3. 生成报告

    report scores.csv --out report.html

预期：当前目录出现 `report.html`，浏览器打开可见表格。

## 下一步

- 想改样式：看「如何自定义报告主题」
- 想懂渲染原理：看「报告渲染机制」
```
