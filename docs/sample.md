# Sample Skill

This file is a working example of a skill definition. Install it, list it, copy it
into a project, then use it as a starting point for your own skills.

```bash
lsm add docs/sample.md global
lsm list global
lsm copy sample
```

## When to use

- You are checking that `lsm` is installed correctly.
- You want a minimal, valid `SKILL.md` to copy and edit.

## Instructions

1. Copy this file and rename the frontmatter `name` to your skill's name.
2. Keep `name` lowercase with single hyphens, at most 64 characters.
3. Keep `description` under 1024 characters and make it a single clear sentence.
4. Put the agent-facing instructions below the frontmatter.
